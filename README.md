# GNOME Beta Store Frontend

This repository hosts the web interface for the [GNOME Beta Store](https://extensions-gnome.github.io). It is a static site that consumes the data from the [Store Backend](https://github.com/extensions-gnome/store).

## Purpose

The GNOME Beta Store provides a modern, fast, and automated way to discover and install GNOME Shell extensions.

Key Features:
* No Browser Plugins: Install extensions via a simple terminal command.
* Fast-Track Updates: Extensions are published as soon as they pass automated audits.
* Transparent Security: View AI audit reports and VirusTotal scan results for every extension.
* Classic Aesthetic: Designed to feel familiar to GNOME users.

## Disclaimer

This is a community-run, unofficial project. We aim to complement the official GNOME Extensions site by offering a faster alternative for developers and users. We have no malicious intent; our goal is purely to improve the developer experience and speed up the availability of extensions.

## Tech Stack
* Frontend: Vanilla HTML5, CSS3, and JavaScript.
* Hosting: GitHub Pages.
* Icons: FontAwesome.
* Data Source: extensions.json from the store repository.
