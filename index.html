About GNOME Beta Store

GNOME Beta Store is an unofficial community initiative.

It was created as a response to the official review bottleneck. We automate security using AI and VirusTotal so that code is available immediately.

This platform is not affiliated with the GNOME Foundation. Use at your own risk.

Developers Guide

Publishing is a process 100% based on GitHub.

  1. Go to our storage repository.
  2. Open an Issue with the corresponding template.
  3. Upload your ZIP and images. Our bot will do the rest.
